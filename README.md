# KnosAI · 企业知识绿洲

> 企业专属的行业知识库平台 — 通过引导式问答 + 文档自动整合，构建贴合企业自身的完整知识库。

**品牌：** KnosAI（域名 knosAI.ltd）
**首期行业：** 环保-污水处理站运维

## 项目结构

```
pulser-landing/
├── index.html     # 落地页主文件
├── spec.html     # 产品设计规范（HTML版）
├── spec.md       # 产品设计规范（Markdown源）
├── imgs/         # 图片资源
│   └── hero-bg.png
└── videos/       # 视频资源
```

## 设计规范

详见 [spec.md](./spec.md) 或 [spec.html](./spec.html)

## 快速开始

直接在浏览器中打开 `index.html` 即可预览。

## 技术栈

- 纯 HTML5 + CSS3 + 原生 JavaScript
- Google Fonts：Noto Sans SC
-移动端优先响应式设计

##部署

部署到 Vercel 或 Netlify，连接 GitHub 即可实现自动部署。
